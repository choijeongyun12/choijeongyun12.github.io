# choijeongyun12.github.io

Source for my academic portfolio & CV, published at [choijeongyun12.github.io](https://choijeongyun12.github.io).

Built on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (itself forked from [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) by Michael Rose), MIT licensed — see `LICENSE`.

## Running locally

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

Then open `http://localhost:4000`.
